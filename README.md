# herdr-app-mods

Mods for the [Herdr](https://herdr.dev) desktop app. Each folder holds `mods/<name>/`, a `RECIPE.md` and a `preview.png`.

- [new-menu-plus](new-menu-plus/RECIPE.md): the tab bar's + menu with pinned and hidden agents.

Code: Apache-2.0 (built from Herdr's shipped `new-menu` mod). Icons: [Lucide](https://lucide.dev), ISC, see `LICENSE-Lucide.txt`.
